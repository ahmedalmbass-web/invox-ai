# INVOX AI

### From Invoice to Intelligent Financial Decisions

INVOX AI is an AI-powered invoice automation platform.

## Core Features

- Invoice management
- AI-powered data extraction
- Supplier management
- Purchase order management
- Three-way matching
- Duplicate invoice detection
- Financial discrepancy detection
- Approval workflows
- Financial reports
- Arabic and English support

## Technology Stack

- Next.js
- React
- TypeScript
- PostgreSQL
- Prisma
- AI and OCR

## Development

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build:

```bash
npm run build
```
